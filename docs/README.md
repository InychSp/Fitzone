# Документація проєкту Fitzone

Аналіз старого сайту на Wix і повний план нового сайту (Python +
Flask): вимоги, структура сторінок, схема БД, зовнішнє API, адмінка.

## Структура

| Файл | Про що |
|---|---|
| `01-project.md` | Що це за проєкт, навіщо переписуємо, обсяг, прийняті рішення, лог змін вимог |
| `02-site-structure.md` | Карта роутів, шапка/футер, модальні вікна, редіректи зі старих Wix-адрес |
| `03-architecture.md` | Загальна архітектура, підсистеми, відкриті питання |
| `04-database.md` | Повна схема БД PostgreSQL (SQLAlchemy) |
| `05-api.md` | Зовнішнє API `servpost.php` — розклад, прайс, оплата LiqPay |
| `06-admin.md` | Адмін-панель: ролі, єдиний інбокс, CRUD-екрани, доступи студентів |
| `pages/` | По одній папці на кожну публічну сторінку старого сайту, з описом за єдиним шаблоном і скріншотами |
| `pages/10-school-instructor/` | Чернетка вимог до майбутнього модуля Школи інструктора (частково узгоджено) |
| `sitemap.md` | ⚠️ Застарів, замінений `02-site-structure.md` — залишений тимчасово для звірки |

## Навіщо це потрібно

Перш ніж писати код, ми фіксуємо, що взагалі є на старому сайті і що
має з'явитись на новому — щоб нічого не забути під час переписування.

## Порядок читання (рекомендовано)

1. `01-project.md` — загальна картина
2. `02-site-structure.md` — де що знаходиться
3. `03-architecture.md` — як компоненти зв'язані між собою
4. `04-database.md` — з чого писати моделі
5. `05-api.md` — як спілкуватись із зовнішнім сервером розкладу/прайсу/оплати
6. `06-admin.md` — що вміє адмінка
7. `pages/*` — детальний опис контенту кожної сторінки
