# Документація проєкту Fitzone

Тут зберігається аналіз старого сайту на Wix і опис того, як кожна
сторінка має бути влаштована на новому сайті (Python + Flask).

## Структура

- `sitemap.md` — повна карта розділів сайту
- `pages/` — по одній папці на кожен розділ, у кожній:
  - `*.md` — опис сторінки за єдиним шаблоном
  - `screenshots/` — знімки екрана старого сайту для цього розділу

## Навіщо це потрібно

Перш ніж писати код, ми фіксуємо, що взагалі є на старому сайті і що
має з'явитись на новому — щоб нічого не забути під час переписування.
