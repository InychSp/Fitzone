# 06. Архитектура и функционал Админ-панели (Admin Panel Specification)

Документ описывает интерфейс, систему ролей и учебный LMS-модуль административной панели FITZONE на Python (Flask-Admin / FastAPI Admin) для управления контентом, ценами, единой лентой входящих сообщений и гибкими доступами учеников школы инструкторов.

---

## 1. Авторизация и Система Ролей

* **Маршрут входа:** `/admin/login`
* **Механизм аутентификации:** Сессионная авторизация на базе хэшированных паролей (`werkzeug.security` / `bcrypt`).

### Матрица прав доступа:

| Раздел админки | Роль: Admin | Роль: Reception |
|---|:---:|:---:|
| **Команда** (`/admin/team`) | Доступен | Заблокирован |
| **Услуги** (`/admin/services`) | Доступен | Заблокирован |
| **Конструктор Цен** (`/admin/prices-config`) | Доступен | Заблокирован |
| **Выдача доступов ученикам (LMS)** (`/admin/students`) | **Доступен** | Заблокирован |
| **Входящие (Единый Inbox)** (`/admin/inbox`) | Доступен | **Доступен (Основной экран)** |

## 2. Разделы и Интерфейс Админ-панели

### 2.1 Интерфейс Роли: Reception (`/admin/inbox`)
Единый агрегатор входящих сообщений из мессенджеров и соцсетей.

* **Верхнее меню:** Содержит только вкладку **«Входящие»** и кнопку выхода из профиля.
* **Левая панель (Список источников и обращений):**
  * Список входящих диалогов, отсортированный по времени (свежие сверху).
  * Бейдж/иконка канала источника: **Telegram, Viber, Instagram**.
  * Имя отправителя / Никнейм / Телефон.
  * Индикатор статуса: *Новое / В работе / Обработано*.
* **Правая панель (Окно диалога/сообщения):**
  * Полный текст пришедшего сообщения.
  * Поле для ответа клиенту напрямую из админки в его мессенджер (Telegram / Viber / Instagram).
  * *Без привязки к внутренней базе клиентов — все входящие мессенджеры собираются в одну ленту.*

---

### 2.2 Модуль «Школа инструкторов» (`/admin/students`) — Доступен только Admin
Управление доступом учеников к учебным материалам с возможностью разделения на блоки.

* **Управление студентами (`/admin/students`):**
  * Форма добавления Email ученика.
  * Настройка уровневого доступа:
    * **Теоретический блок** (доступ к закрытым видеолекциям и теории).
    * **Практический блок** (доступ к практическим материалам/заданиям).
  * При внесении Email система генерирует временный пароль/ссылку для входа и отправляет приглашение на почту.
  * Статус доступа ученика: `Активен` / `Заблокирован`.
* **Закрытый раздел для учеников на сайте (`/school/lessons`):**
  * Авторизация ученика по Email и паролю.
  * Отображение разрешенных разделов (Теория / Практика) в зависимости от выданных прав в админке.

---

### 2.3 Разделы Роли: Admin

1. **Управление Командой (`/admin/team`):**
   * Просмотр, создание и редактирование карточек тренеров.
   * Загрузка фото, выбор категорий (M2M), назначение квалификации (Classic/PRO/VIP) и установление цен.
   * Переключатель видимости на сайте (`is_published`) и сортировка.

2. **Управление Услугами (`/admin/services`):**
   * Редактирование каталога групповых программ.
   * Настройка возрастной категории ("18+"), видео-обзоров и типа абонементов.

3. **Конструктор Цен и Конфигурации (`/admin/prices-config`):**
   * Редактирование 4 конфигурационных таблиц прайс-листа (`price_groups_config`, `price_plans_config`, `price_rules_config`, `price_names_config`).
   * Настройка плашек инфо и условий посещения.

4. **Кэш и Системные функции (`/admin/system-status`):**
   * Ручной сброс кэша расписания `schedule_cache`.
   * Импорт и экспорт данных в CSV.

## 3. Схема маршрутов (Admin & LMS Routes)

| URL | Метод | Допустимые Роли | Описание |
|---|---|---|---|
| `/admin/login` | GET / POST | Все | Форма авторизации в админку |
| `/admin/inbox/` | GET | Admin, Reception | Единый агрегатор сообщений (Telegram, Viber, Instagram) |
| `/admin/inbox/<id>` | GET / POST | Admin, Reception | Просмотр и ответ на сообщение из канала |
| `/admin/students/` | GET / POST | Admin | Выдача и разделение доступов учеников (Теория / Практика) |
| `/school/login` | GET / POST | Ученик (Student) | Страница входа для учеников |
| `/school/lessons` | GET | Авторизованный ученик | Закрытая страница с учебными материалами |
| `/admin/team/` | GET / POST | Admin | Управление тренерами |
| `/admin/services/` | GET / POST | Admin | Управление групповыми услугами |
| `/admin/prices-config/` | GET / POST | Admin | Управление конфигуратором цен |
