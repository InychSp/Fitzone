# 02. Карта сайта, роуты и сквозные блоки (Site Structure & Routes)

Документ описывает глобальную структуру страниц сайта FITZONE, карту роутов (URL-адресов) для backend-приложения, а также сквозные элементы интерфейса (шапка, футер, модальные окна), одинаковые для всех страниц.

---

## 1. Сквозные блоки интерфейса (Global Layout Components)

Эти компоненты входят в базовый шаблон (`base.html`) и рендерятся на каждой странице сайта.

### 1.1 Шапка сайта (Header / Navigation Bar)
* **Логотип FITZONE**: Кликабельный, ведет на главную страницу (`/`).
* **Главное меню**:
  * **Главная** (`/`)
  * **Послуги ▾** (Выпадающее меню категорий / прямое действие):
    * Тренажерний зал (`/services/gym`)
    * Групові тренування (`/services/group-training`)
    * Реабілітація (`/services/rehabilitation`)
    * Масаж (`/services/massage`)
    * Сауна (`/services/sauna`)
    * Солярій (`/services/solarium`)
  * **Розклад** (`/schedule`)
  * **Ціни** (`/price`)
  * **Команда** (`/team`)
  * **Школа інструкторів ▾** (`/school/instructor`)
* **Кнопка быстрых действий / Контакты**:
  * Быстрая ссылка на телефон клуба или модальное окно записи/оплаты.
  * Переключатель языка (если предусмотрена мультиязычность).

### 1.2 Футер сайта (Footer)
* **Блок 1: О клубе / Логотип**: Короткое описание фитнес-комплекса FITZONE в Днепре.
* **Блок 2: Быстрые ссылки**: Повтор основных разделов сайта.
* **Блок 3: Контакты и время работы**:
  * Адрес комплекса (г. Днепр, ...).
  * Телефоны рецепции.
  * График работы (пн-сб, вс).
* **Блок 4: Соцсети и Мессенджеры**: Ссылки на Instagram, Telegram, Facebook, Viber.
* **Блок 5: Юридическая информация и оплата**:
  * Публичная оферта (`/legal/terms`)
  * Политика конфиденциальности (`/legal/privacy`)
  * Правила клуба (`/legal/rules`)
  * Иконки платежных систем (LiqPay, Visa, Mastercard).
* **Копирайт**: `© FITZONE 2026. Всі права захищені.`

## 2. Карта роутов backend-приложения (Route Mapping)

Маппинг старых URL (Wix) на новые роуты приложения Flask/FastAPI:

### 2.1 Публичные страницы (Public Routes)

| Название страницы | Новый Route (URL) | Код шаблона (Jinja2) | Старый URL (Wix) | Источник данных |
| :--- | :--- | :--- | :--- | :--- |
| **Головна** | `/` | `index.html` | `/` | Локальная БД + Промо-блоки |
| **Тренажерний зал** | `/services/gym` | `pages/gym.html` | `/gym` | БД (`services`) + API Прайсов |
| **Групові тренування** | `/services/group-training` | `pages/group_training.html` | `/poslugy` | БД (`group_training_services`) |
| **Реабілітація** | `/services/rehabilitation` | `pages/rehabilitation.html` | `/rehabilitation` | БД (`services`, `team_members`) |
| **Масаж** | `/services/massage` | `pages/massage.html` | `/massage` | БД (`services`) + API Прайсов |
| **Сауна** | `/services/sauna` | `pages/sauna.html` | `/sauna` | БД (`services`) + API Прайсов |
| **Солярій** | `/services/solarium` | `pages/solarium.html` | `/solarium` | БД (`services`) + API Прайсов |
| **Розклад** | `/schedule` | `pages/schedule.html` | `/schedule` | API `servpost.php` + Кеш БД |
| **Ціни (Прайс)** | `/price` | `pages/price.html` | `/price` | API `servpost.php` + 4 таблицы конфига |
| **Команда** | `/team` | `pages/team.html` | `/team` | БД (`team_members`) |
| **Школа інструктора** | `/school/instructor` | `pages/school.html` | `/school-instructor` | Текстовый модуль / БД |

### 2.2 Юридические и информационные страницы (Legal Routes)

| Название страницы | Route (URL) | Описание |
| :--- | :--- | :--- |
| **Публічна оферта** | `/legal/terms` | Договор публичной оферты и условия услуг |
| **Політика конфіденційності** | `/legal/privacy` | Политика обработки персональных данных |
| **Правила клубу** | `/legal/rules` | Регламент посещения фитнес-комплекса |

### 2.3 Служебные / API роуты (Internal & API Routes)

| Route (URL) | Метод | Описание |
| :--- | :--- | :--- |
| `/api/v1/schedule` | GET | Получение расписания (из локального кэша) |
| `/api/v1/price` | GET | Получение актуальной сетки цен для виджетов |
| `/api/v1/payment/callback` | POST | Callback-обработчик ответов от LiqPay |

## 3. Административный раздел (Admin Routes)

Роуты системы управления контентом (доступны только авторизованным администраторам):

| Route (URL) | Метод | Описание |
| :--- | :--- | :--- |
| `/admin/login` | GET / POST | Форма входа в панель администратора |
| `/admin/logout` | GET | Выход из системы |
| `/admin/dashboard` | GET | Главная панель / обзор состояния системы |
| `/admin/team` | GET / POST | Управление составом команды (`team_members`) |
| `/admin/team/<id>` | PUT / DELETE | Редактирование / удаление тренера |
| `/admin/services` | GET / POST | Управление каталогом услуг |
| `/admin/price-config` | GET / POST | Управление 4 таблицами конфигуратора цен |

## 4. Глобальные модальные окна (Modals)

1. **Модалка оплаты абонемента (`#payment-modal`)**:
   * Вызывается со страницы `/price` или со страниц услуг.
   * Форма ввода контактных данных (Имя, Телефон, Email).
   * Выбор условий / времени и генерация формы перенаправления на LiqPay.
2. **Модалка детальной информации о тренере (`#trainer-modal`)**:
   * Вызывается на страницах `/team`, `/services/massage`, `/services/rehabilitation`.
   * Показывает расширенную биографию, фото, квалификацию и Instagram.
