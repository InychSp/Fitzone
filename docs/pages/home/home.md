# Головна сторінка

**URL на старому сайті:** https://www.fitzone.com.ua/
**Майбутній route у Flask:** /

## Призначення
Перше враження про клуб, швидка навігація по всіх напрямках, заклик записатись.

## Контент і блоки
1. Шапка: лого + меню (Головна, Послуги ▾, Команда, Розклад, Прайс, Школа інструктора ▾, Блог)
2. Hero: фото + заголовок "ФІТНЕС ПРОСТІР - СТИЛЬ ЖИТТЯ", підзаголовок "1800 кв. загального простору", 3 пункти з іконками (тренування / сауна-масаж-бар / застосунок Fitcontrol)
3. Блок "НАПРЯМКИ / ДОДАТКОВІ ПОСЛУГИ" — плитка 4 послуг (сауна, солярій, масаж, спортбар) з кнопками "Детальніше"
4. Промо мобільного застосунку Fitcontrol — список фіч + кнопки Google Play / App Store
5. Блок "НАША КОМАНДА" — прев'ю тренерів + посилання "Усі тренери"
6. Футер: соцмережі, юридичні посилання, партнери, оплата, контактний email

## Що буде динамічним
- Прев'ю тренерів у блоці "Команда" (з БД, синхронізовано зі сторінкою /team)

## Що статичне
Все інше — hero, блок послуг, футер

## Форми / інтеграції
Немає власної форми, тільки посилання на застосунок Fitcontrol (сторонній, не робимо самі)
